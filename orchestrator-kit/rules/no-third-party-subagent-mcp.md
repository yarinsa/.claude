# Third-party sub-agent MCP servers - opted out (optional rule; delete if you use them)
- Never call another vendor's coding-agent MCP tools as sub-agents, at any model or effort; a permission prompt is not permission. Sole exception: the user asks for that tool by name in this session. Route the work to Claude agents per the playbook routing table.
- Review bots that act through the code host (a GitHub app commenting on PRs) are not MCP sub-agents and stay allowed.
